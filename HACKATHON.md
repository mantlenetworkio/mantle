+# Mantle Mash Hackathon Bounties
+
+This document provides clarity on hackathon bounties tracked in this repository.
+
+## DeFi Project Bounty (Issue #598)
+
+- **Prize:** $2,500 per team (2 winning teams)
+- **Challenge:** Create a DeFi implementation (e.g., Stableswap, UniswapV2 with veEconomics and Gauges) on Mantle.
+- **Requirements:** Deploy on Mantle testnet, submit a video demo, and provide a separate GitHub repository.
+
+> **Note for Contributors:** This issue is a hackathon bounty for the ecosystem. It does not require bug fixes or feature implementations in the core Mantle network codebase. Submissions should be made via independent project repositories.
